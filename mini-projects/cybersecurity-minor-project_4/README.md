## GitHub upload
Create an empty repository on GitHub (private is safest until screenshots are reviewed), then run:

```bash
cd Cybersecurity_Mini_Project_Submission
git init
git add .
git commit -m "Add cybersecurity minor project report"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/cybersecurity-minor-project.git
git push -u origin main
```

Replace the username and repo URL. Never commit tokens, passwords, session cookies, or private evidence.
